# PARALLEL-001 — Vietnamese onboarding messages

As a Vietnamese-speaking user, I want clear messages when onboarding starts and completes.

- AC-1: `messages/welcome.txt` contains exactly one line: Chào mừng bạn đến với Storyflow!
- AC-2: `messages/complete.txt` contains exactly one line: Bạn đã hoàn tất thiết lập.
- Each message is encoded in UTF-8 without BOM.
